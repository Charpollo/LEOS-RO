## Visual Features for Red Orbit (3D Strategic View)

### 1. **Threat Probability Clouds**
Instead of a single trajectory line, show:
- Translucent probability envelope that expands over time
- Color gradient: Red (90% probability) → Yellow (50%) → Green (10%)
- Real-time updates as new sensor data refines the prediction
- Multiple hypothesis tracks for ambiguous launches

### 2. **Kill Web Visualization**
Show the entire defensive ecosystem:
- All sensors currently tracking (radar cones, optical FOVs)
- Defensive satellites that could respond
- Ground-based interceptors in range
- Time windows for each defensive option
- Success probability for each countermeasure

### 3. **Debris Cascade Simulation**
When an intercept occurs:
- Particle system showing debris cloud expansion
- Each fragment with calculated orbital trajectory
- Color-coded by size: Red (>10cm lethal), Yellow (1-10cm), Green (<1cm)
- Time-lapse showing debris spreading over hours/days
- Affected satellites highlighted as debris approaches

### 4. **Multi-Domain Correlation**
Split screen showing:
- Space domain: Satellite positions and threats
- Cyber domain: Network attacks on ground stations
- EM spectrum: Jamming and interference patterns
- Ground domain: Launch sites, tracking stations
- All synchronized to same timeline

### 5. **Decision Timeline Interface**
Floating timeline bar showing:
- "Launch detected" → "Track confirmed" → "Target identified" → "Last maneuver window" → "Impact"
- Color changes from green → yellow → red as time critical
- Countdown timers for each decision point
- Auto-generated decision brief at each stage
