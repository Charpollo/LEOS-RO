# 🔒 Enable Invite-Only Mode - Quick Guide

## Step 1: Go to Netlify Dashboard
1. Go to: https://app.netlify.com
2. Click on your RED ORBIT site

## Step 2: Navigate to Identity Settings
1. Click **"Identity"** in top menu
2. Click **"Settings and usage"**

## Step 3: Enable Invite-Only
1. Find **"Registration preferences"** 
2. Click **"Edit settings"**
3. Select **"Invite only"**
4. Click **"Save"**

## ✅ DONE! 

Now:
- Public signups are DISABLED
- Only invited users can access
- Login page shows "Invite-Only Beta" message
- Users see: "Request access: mission@cyberrts.com"

## How to Send Invites

### Method 1: Individual Invites
1. Go to **Identity** tab
2. Click **"Invite users"**
3. Enter email address
4. Click **"Send"**

### Method 2: Bulk Invites
1. Create a text file with emails (one per line):
```
user1@example.com
user2@example.com
user3@example.com
```
2. Go to **Identity** → **"Invite users"**
3. Paste all emails
4. Click **"Send invites"**

## What Invited Users See
1. Email: "You've been invited to RED ORBIT Beta"
2. Click link in email
3. Set their password
4. Access granted!

## Managing Beta Users
- **View all users:** Identity tab
- **See pending invites:** Identity → Invites
- **Revoke access:** Identity → Select user → Delete
- **Export emails:** Identity → Download CSV
